# Telegram Username Finder Bot

Этот проект — пример Telegram-бота, который позволяет искать людей по никнейму внутри собственной базы данных (которую вы наполняете командами бота). **Важное ограничение:** Telegram Bot API не позволяет находить произвольных пользователей Telegram по никнейму, если они не взаимодействовали с ботом. Поэтому бот хранит локальный каталог пользователей и ищет по нему.

## Возможности
- `/add <username> <контакт>` — добавить запись в каталог.
- `/find <username>` — найти запись по никнейму.
- `/help` — справка.

## Установка

> В большинстве Linux окружений `python` не установлен по умолчанию, используйте `python3`.

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

## Настройка

Создайте переменную окружения с токеном бота:

```bash
export BOT_TOKEN="<YOUR_TELEGRAM_BOT_TOKEN>"
```

## Запуск

```bash
python bot.py
```

## Если видите ошибки установки

- `Command 'python' not found` — используйте `python3` и создавайте виртуальное окружение через `python3 -m venv .venv`.
- `externally-managed-environment` (PEP 668) — устанавливайте зависимости **только** внутри `.venv`, как в шаге установки выше.

## Пример использования

```
/add johndoe https://t.me/johndoe
/find johndoe
```

## Как расширить

- Добавить модерацию записей.
